# Metaversus - Modern UI/UX Website

A fully responsive, modern front-end application demonstrating advanced UI/UX principles and smooth animations. Built with Next.js 13, Tailwind CSS, and Framer Motion to create a highly engaging, futuristic web experience.

🌐 **[Live Demo](https://metaversus-iota.vercel.app/)**

## Features

- **Fluid Animations:** Complex, scroll-triggered animations, page transitions, and interactive elements powered by Framer Motion.
- **Modern UI Design:** A clean, futuristic aesthetic built entirely with Tailwind CSS utility classes.
- **Fully Responsive:** Carefully optimized to look perfect across mobile, tablet, and desktop viewports.
- **Component-Driven Architecture:** Clean codebase separating layout sections (Hero, Explore, Insights, World) into modular, reusable React components.

## Technologies Used

- **Framework:** Next.js 13, React 18
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Deployment:** Vercel

## Local Setup

To run this project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/Akash4510/metaversus.git](https://github.com/Akash4510/metaversus.git)
   cd metaversus
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
